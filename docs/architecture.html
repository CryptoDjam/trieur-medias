Trieur de médias — une page locale pour trier des photos

Projet de Cyril M (MIT) · version 0.1.0, état au 5 octobre 2026 · code : ~/Projects/trieur-medias/ · npm trieur-medias · github.com/CryptoDjam/trieur-medias

1. Le principe

Un serveur Python (bibliothèque standard, rien à installer) sert une page HTML/JS sur 127.0.0.1:9170. La page montre un dossier du dossier personnel en bande de vignettes et en vue grande ; on coche, puis on envoie la sélection vers un autre dossier ou à la corbeille du système. Le .json jumeau d'une image (réglages ComfyUI) suit l'image partout. Tout reste sur la machine.

2. Les deux flux qui modifient des fichiers

Envoyer vers… (déplacer)

  1. La page demande GET /api/choisir?depuis=<dossier>&titre=… : le serveur lance choisir-dossier.py (GTK) et renvoie le dossier choisi, ou {annule}.
  2. La page envoie POST /api/deplacer {chemins, dossier} avec les fichiers cochés.
  3. Le serveur vérifie : chaque chemin et le dossier d'arrivée sont dans $HOME ; le dossier d'arrivée existe et n'est pas le dossier source ; aucun fichier du même nom n'existe déjà à l'arrivée (sinon refus, pas d'écrasement). Pour une image, le .json de même nom est ajouté aux cibles. Puis shutil.move.
  4. Réponse {dossier, deplaces, refuses} ; la page recharge le dossier et garde le fichier affiché s'il est encore là.

Supprimer (corbeille)

  1. Confirmation dans la page (Entrée / Échap).
  2. POST /api/corbeille {chemins} → pour chaque fichier (et son .json jumeau), gio trash. Jamais rm : tout se récupère dans Fichiers → Corbeille.

3. Garde-fous

5. Limites connues et suite possible

  • Pas d'aperçu pour les formats hors image / vidéo / texte (nom et taille seulement).
  • Un fichier ouvert depuis le bureau ouvre une nouvelle fenêtre appli si une fenêtre du Trieur existe déjà.
  • Sans GTK, la boîte « choisir un dossier » est absente : on tape le chemin ; le bouton « Envoyer » renvoie alors une erreur explicite.
  • Suite envisagée : notes.json par dossier (messages attachés à un média), copie en plus du déplacement, renommage.
